How the radar values a launch

Honest limits. “Records no token” means this snapshot records none — a parent protocol can hold the token and stay invisible here, so no row is ever called tokenless, only unrecorded. An implied value is a model's estimate from this snapshot: not a price, not a promise, and never a reason to farm blindly. Farm plans name a cost and a time for every step; never pay to claim.
